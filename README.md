# Scanner beast

CamScanner-style document scanner that runs entirely in the browser.

- Opens on a library of saved scans (default: newest first; sort by name or size, top right)
- Scan button opens the camera; after the shot the paper is detected and cropped automatically
- Perspective correction, shadow removal, filters, manual corner adjust
- Multi-page documents, rename / reorder / delete, export to PDF / JPG / PNG
- Scans are stored locally in the browser (IndexedDB)

Live camera needs https (GitHub Pages works).
